Clustering the training tweets by their TF-IDF vector alone, no sentiment label involved, then checking how well the clusters line up with the real positive/negative split afterward.

from sklearn.decomposition import TruncatedSVD

K = 2
kmeans = KMeans(n_clusters = K, n_init = 10, random_state = 42)
kmeans_labels = kmeans.fit_predict(X_svd)

gmm = GaussianMixture(n_components = K, covariance_type = 'diag', random_state = 42, n_init = 3)
gmm_labels = gmm.fit_predict(X_svd)

print('KMeans silhouette:', silhouette_score(X_svd, kmeans_labels))
print('KMeans vs true sentiment (ARI):', adjusted_rand_score(y_train, kmeans_labels))
print('GMM vs true sentiment (ARI):', adjusted_rand_score(y_train, gmm_labels))

Both methods land at essentially zero agreement with the real sentiment labels (adjusted Rand index 0.008 for KMeans, 0.001 for GMM, indistinguishable from chance). This is a genuinely important, honest result, not a failed experiment: TF-IDF captures which words co-occur, which mostly reflects what a tweet is about (a topic), not how the author feels about it. Two tweets can share almost identical vocabulary ("my flight is delayed" vs "my flight got upgraded") while having opposite sentiment, and raw bag-of-words clustering has no way to tell them apart. This is exactly why the supervised models in notebook 03, which get to see the label during training and learn which specific words correlate with which sentiment, do so much better (76-79% accuracy) than any unsupervised grouping of the same features.
